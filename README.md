This game is a revisited fan-version of Ballistix minigame from Crash Bash (PSX).

# Gameplay 👾
Spaceball is a 4-player air hockey game where each player has to score against the others and avoid getting scored on.

# How To Play ℹ️
Move your ship and use the impulse ability to deflect the balls away from your zone.
Win by being the last player standing.

# Controls 🎮
Use A and D or Left stick from the gamepad to move the spaceship.

Use Spacebar or A button from the gamepad to use the Impulse ability
